# 📌 Featured Projects

## 🔹 AIOps Root Cause Analysis Platform

🔗 https://github.com/princelevin/aiops-root-cause-platform

AI-powered AIOps platform built using React, FastAPI, PostgreSQL, Redis, Docker, and Ollama.

* Built an AI-powered observability platform capable of detecting incidents and generating Root Cause Analysis (RCA).
* Developed an incident correlation engine using severity, affected service, failure type, and root-cause hints.
* Integrated local LLMs through Ollama to generate actionable AI RCA recommendations.
* Designed real-time dashboards for telemetry monitoring, service health tracking, and incident prioritization.
* Implemented AI guardrails, Redis timeout simulation, database pool exhaustion scenarios, and resilience testing workflows.

## 🔹 Resilient Microservices Backend System

🔗 https://github.com/princelevin/resilient-microservices-backend

Production-style distributed backend platform demonstrating reliability engineering patterns.

* Built API Gateway, Auth Service, Product Service, Order Service, and Payment Service using Node.js and Express.
* Implemented JWT authentication and secure service-to-service communication.
* Integrated PostgreSQL persistence and Redis cache-aside architecture.
* Added resilience patterns including circuit breakers, retries, timeouts, and failure simulations.
* Containerized the entire platform using Docker Compose with structured JSON logging and observability support.
